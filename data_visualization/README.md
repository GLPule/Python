# Data Visualization

This project folder focuses on creating charts and visualizations using Python libraries such as Matplotlib, Seaborn, and Plotly. It includes practice notebooks covering basic plotting, chart customization, and different visualization styles.

## Project Goals

- Learn how to turn raw data into meaningful charts
- Explore common chart types such as line, bar, pie, scatter, and bubble plots
- Understand how to customize plot style, colors, labels, legends, and axes
- Compare static and interactive visualization libraries

## Included Files

- `data_visualization.ipynb` — introductory notebook covering Matplotlib, Seaborn, and Plotly
- `data_visualization_chart_customization.ipynb` — notebook focused on styling, themes, colors, markers, gridlines, and layout customization
- `retail_sales.csv` — sample dataset used in the visualizations

## Libraries Used

- Line charts

- Horizontal bar charts

- Scatter plots

- Plot styling and formatting
- Interactive visualizations

## How to Use

1. Open the notebooks in Jupyter Notebook or VS Code with Python support.
2. Run the cells in order to generate the visualizations.
3. Modify the sample data or chart settings to experiment with different outcomes.

## Example Setup

Install the required packages if needed:

```bash
pip install matplotlib seaborn plotly pandas numpy
```

Then open either notebook and run the cells.

## Notes

This project is intended as a learning exercise for data visualization and chart design. It demonstrates both foundational plotting concepts and more polished presentation techniques.
